Agent Retention Benchmark

Simulated

How to read whether agents stay alive. These bands are targets Totem is proposing. No public agent-retention benchmark exists yet. Every number on this dashboard is simulated.

Death rule

An agent is dead after N consecutive inactive days. N is adjustable from 1 to 14 on the Retention page, and the default is 5. Reactivation means a dead agent resumes: it sends a message, runs a search, or completes a task again, and it returns to the live count.

Long-running agents

Use a 5-day death rule. These agents are expected to show up most days, so a short quiet stretch is a real loss.

Task-based (spiky) agents

Use a 14-day death rule. Work arrives in bursts, then goes quiet. A short death window treats that pause as churn.

Short death windows overstate churn for spiky agents. In the simulation, 91% of 5-day deaths later resumed.

Net agent retention

Net agent retention is live agents in a cohort at week N, divided by live agents in that cohort at week 0. New agents added later by the same customers count in the numerator. It is not logo retention, and it is not revenue retention.

The Good, Great, and Best bands above are Totem-proposed targets, because no public agent-retention benchmark exists. All dashboard data is simulated.
